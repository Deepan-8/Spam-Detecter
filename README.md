📧 Spam Detection Web App :
    This is a simple web application built with **Flask** that classifies text messages as **Spam** or **Not Spam** using a trained machine learning model.

🚀 Features
    - User-friendly web interface.
    - Enter a text message and check if it is spam.
    - Uses a pre-trained ML model (`model.pkl`) and text vectorizer (`vectorizer.pkl`).

🛠️ Technologies Used
    - **Python 3**
    - **Flask** (Web Framework)
    - **Scikit-learn** (Machine Learning)
    - **Pickle** (Model Serialization)
    - **HTML/CSS** (Frontend)
